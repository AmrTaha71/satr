# ستر — القطعة الأولى: وضع حراسة iOS في المقدمة

> **إنذار حركة + صفارة إنذار حريق + مهلة 3 ثوانٍ — على آيفون/آيباد عمرو أولًا.**
> من قوله تعالى: ﴿وَلَا تَجَسَّسُوا﴾ (الحجرات: 12).
> مجاني، بلا إعلانات، بلا حساب، بلا خادم — كل شيء على هاتفك فقط.

## انقلاب المنصة (قرار §9/1 — أجابه عمرو 2026-11-12 00:30)

المخطط الأصلي أوصى بـ Android أولًا بالقدرة الكاملة. عمرو قلَب الترتيب:
**iOS أولًا** — لأنه يختبر على آيفونه/آيباده، ولا يستطيع اختبار Android.
Android ثانيًا.

لذلك القطعة الأولى الآن هي **نسخة iOS الممكنة فقط**:
- إنذار حركة والتطبيق مفتوح في المقدمة (CoreMotion DeviceMotion).
- صفارة إنذار حريق تتجاوز مفتاح الصمت (فئة playback).
- مهلة 3 ثوانٍ بنافذة Face ID / Touch ID.
- عد تنازلي 10 ثوانٍ + رمز إيقاف 4 أرقام.
- إعداد أول مرة (رمز الإيقاف + بصمة، 60 ثانية).

ونسخة Android الكاملة (خدمة أمامية + قفل تطبيقات) **ثانية، لا أولى** —
كودها Kotlin موجود في الشجرة لكنه غير مترجَم وغير مختبَر، ولا يُقدَّم
على أنه القطعة الأولى.

## ما هذه القطعة؟ (مخطط §10، بعد الانقلاب)

مشروع React Native (Bare) + TypeScript فيه:

- شاشة رئيسية بزر واحد كبير («فعّل الحماية») + عد تنازلي 10 ثوانٍ.
- قراءة DeviceMotion (تسارع + جيروسكوب + زاوية ميل) بعتبة حساسية واحدة افتراضيًا («جالس بجانبي»)، مع مستويات الحساسية الثلاثة في النواة.
- مهلة 3 ثوانٍ بنافذة Face ID / Touch ID الرسمية.
- ملف صفارة إنذار حريق محلي يُشغَّل عبر فئة التشغيل (playback) ويتوقف ببصمة/وجه المالك أو رمز إيقاف 4 أرقام.
- إعداد أول مرة (رمز الإيقاف + بصمة، 60 ثانية).
- الوضع صارم: بعد المهلة تبدأ الصفارة فورًا بلا شاشة تحذير — ولا وضع مهذب ولا مرحلة تحذير في الكود إطلاقًا.

## ⚠️ ما لم يُتحقق منه — اقرأ هذا أولًا

- **الكود الأصلي (Kotlin/Swift) غير مترجَم:** جهاز البناء هذا بلا Android SDK وبلا Xcode، فلم تُترجَم أي وحدة أصلية هنا ولم يُختبر أي شيء على جهاز. **لا يوجد اختبار جهاز ناجح في هذه القطعة — ولا يُدَّعى ذلك في أي مكان.**
- **النواة المشتركة (TypeScript) فقط هي التي فُحصت نوعيًا** على هذا الجهاز (`npm run typecheck:core` — انظر «التحقق» أدناه). واجهة React Native تحتاج `npm install` كاملًا على MacBook قبل فحصها نوعيًا.
- **كل الأرقام تقديرات غير مقيسة:** عتبات الحساسية (0.15g / 0.5g / 0.05g)، «1–2% بطارية في الليلة»، «الصفارة تصل للأقصى خلال 5 ثوانٍ»، تجميع الحوادث خلال 5 دقائق. يجب قياسها على أجهزة حقيقية قبل كتابتها في التطبيق أو المتجر — الواجهة تعرض «لم يُقَس بعد» حتى يُقاس.
- **الرسالة العربية المنطوقة — النص معتمَد والتسجيل غير موجود بعد:** النص هو الآية «وَلَا تَجَسَّسُوا وَلَا يَغْتَب بَّعْضُكُم بَعْضًا» (الحجرات 49:12، قرار §9/3). لكن `voice_message.m4a` لم يُسجَّل بعد — حتى يُسجَّل، الصفارة وحدها هي ما يُسمع فعليًا. الصرخة البشرية أُلغيت بقراره ولا ملف لها.
- **دليل المتطفل (صورة + فيديو 5 ثوانٍ) لم يُبنَ بعد:** منفذ placeholder فقط في `GuardRuntime` — لا كود كاميرا في هذه القطعة (المرحلة 3).
- **مشروع Xcode غير موجود بعد:** الشجرة فيها مصادر Swift وPodfile، لكن لا يوجد `ios/*.xcodeproj` ولا `xcworkspace`، و`siren.wav` ليس في حزمة iOS. `pod install` والبناء على MacBook يحتاجان توليد المشروع أولًا (انظر «كيف تُشغَّل» أدناه).
- **لا `gradlew` في الشجرة:** بناء Android وCI (`./gradlew bundleRelease`) يحتاجان توليد الـwrapper على MacBook أولًا.
- **CI ما زال Android فقط:** لا وظيفة iOS (TestFlight) بعد — مع أن iOS أولًا الآن.
- **رمز الإيقاف على iOS لجلسة واحدة فقط:** سجله (Salt + Hash) يبقى في الذاكرة حتى يُبنى جسر Keychain لـ GuardModeModule — يُفقد بإغلاق التطبيق. على Android يُخزَّن في Keystore أصليًا.

## إصلاحات المراجعة النهائية (2026-11-12 — المشرف)

أخطاء وجدتها المراجعة وأُصلحت في مكانها (كلها موثقة في تقرير المراجعة):
- **ربط بدء الحراسة كان مفقودًا:** `startGuardMode()` لم يكن يُستدعى من JS إطلاقًا — فلم تكن أي عينة حساس لتصل على جهاز حقيقي. الآن `App.tsx` يشغّل/يوقف الحراسة الأصلية مع حالة النواة (iOS وAndroid).
- **رمز الإيقاف كان يُنسى فور الإعداد:** `SetupScreen` لم يكن يحفظ الرمز في أي مكان، و`HomeScreen` كان يستدعي `AlarmModule` (غير موجود على iOS) — فلا بصمة ولا رمز كانا ليعملا على آيفون. الآن السجل (Salt + Hash) يُسلَّم لـ App ويُخزَّن في Keystore على Android / في الذاكرة لجلسة واحدة على iOS، والبصمة عبر الوحدة المشتركة.
- **الحساسية كانت زرًا بلا أثر:** اختيارها في الواجهة لم يكن يصل للنواة. الآن `GuardRuntime.setSensitivity` + ربط الشاشة.
- **الجسر كان يكذب:** `bridge.ts` وصف وحدة Android واحدة؛ الآن واجهتان حقيقيتان (iOS/Android) + تمييز توقيع `startScream` بين المنصتين.
- **Android:** اسم حدث العينات كان `WalaTajassasuSensor` بينما الواجهة تستمع لـ `GuardSensorSample` (أُصلح الاسم)؛ أحداث الجيروسكوب كانت تُمرَّر كتسارع فتُنتج رفعًا كاذبًا (تُصفَّى الآن)؛ زر «أوقف الحماية» في الإشعار كان بلا أثر (يوقف الخدمة الآن)؛ `MediaPlayer.create` كان يُستدعى بتوقيع غير موجود (استُبدل بـ `MediaPlayer` + `setDataSource`).
- **Swift:** بدء حراسة مكرر كان يراكم مراقب انقطاع؛ مؤقّت تدرّج الصوت كان قد لا يعمل خارج الخيط الرئيسي (يُجدوَل على Main الآن).
- **نوع «صامت» أُزيل من الكود:** `IntruderEvidenceMethod` كان يسمح بـ `'silent'` كقيمة — الآن `'visible-preview'` فقط.
- **الاختبارات صارت في الشجرة:** كانت نتائج اختبار بلا ملفات — الآن `src/core/__tests__/core.test.ts` + `jest.config.js` (انظر «التحقق»).

## كيف تُشغَّل على MacBook + Xcode (iOS أولًا)

**ملاحظة — الملفات الثنائية:** الملفات الثنائية (siren.wav وgradle-wrapper.jar
وdebug.keystore وأيقونات التشغيل) محفوظة كملف نصي base64 واحد
(`binaries.tar.gz.b64`) لأن الرفع لا يحمل ملفات ثنائية. بعد الاستنساخ،
شغّل أولًا:
```bash
python3 scripts/restore-binaries.py
```
ده بيرجّع الـ 15 ملف لمكانها. من غير الخطوة دي، بناء Android هيفشل
(ناقص siren.wav وgradle-wrapper.jar وdebug.keystore).

مشروع Xcode موجود في الشجرة (`ios/WalaTajassasu.xcodeproj` — أُنشئ 2026-11-18
وتحقق منه 69/69)، و`siren.wav` مربوط في موارد الحزمة (Copy Bundle Resources).
الخطوات:

```bash
cd satr
python3 scripts/restore-binaries.py   # استرجاع الملفات الثنائية (مرة واحدة بعد الاستنساخ)
npm install
npm run typecheck        # فحص نوعي كامل (يحتاج node_modules)
npm run typecheck:core   # فحص النواة المشتركة فقط
npm test                 # اختبارات النواة (src/core/__tests__/core.test.ts)
cd ios && pod install
# افتح ios/WalaTajassasu.xcworkspace في Xcode، وصّل آيفون/آيباد حقيقيًا، واضغط Run
# (ليس المحاكي — المحاكي بلا حساسات حركة حقيقية)
```

أو: `npx react-native run-ios --device` من الطرفية على MacBook.
لـ Android (ثانيًا): `gradlew` موجود في الشجرة،
ثم `npx react-native run-android` أو افتح مجلد `android/` في Android Studio.

نص اختبار القبول على الجهاز: [`docs/DEVICE-TEST.md`](docs/DEVICE-TEST.md) — أربعة سيناريوهات على iOS أولًا، وملحق Android للمرحلة الثانية.

## حدود iOS — بصدق (مخطط §2 و§8، أفكار §3)

| الميزة | iOS (أولًا) | Android (ثانيًا) |
|---|---|---|
| إنذار الحركة والتطبيق مفتوح | ✓ (وضع حراسة — القطعة الأولى) | ✓ |
| إنذار الحركة والشاشة مقفلة | ✗ مستحيل عمليًا — البديل وضع حراسة مفتوح فقط | ✓ خدمة أمامية (ليست مضمونة دائمًا) |
| قفل تطبيقات أخرى (واتساب) | ✗ **مستحيل** — البديل: خزنة داخلية + دليل Screen Time | ✓ (المرحلة 2): واتساب + تيليجرام + ماسنجر + المعرض/الصور؛ بلا إيميل |
| الصفارة تتجاوز الصامت | ✓ فئة playback — لكن لا رفع صوت النظام برمجيًا إلى الأقصى | ✓ STREAM_ALARM |
| صورة المتطفل | ◐ معاينة ظاهرة فقط والتطبيق مفتوح (المرحلة 3) — لا كاميرا صامتة إطلاقًا | ◐ ممكن تقنيًا (المرحلة 3) — بمعاينة ظاهرة، لا التقاط صامت إطلاقًا |
| فيديو 5 ثوانٍ للمتطفل | ◐ مخطط في المرحلة 3، في المقدمة فقط — لم يُختبر | ◐ مخطط في المرحلة 3 عبر الخدمة الأمامية — لم يُختبر |
| فتح بصورة للمالك | ✗ Face ID يرفض الصورة أصلًا | ✗ نفس الشيء — القيمة هي الصفارة والردع، لا كشف الصورة |
| تشغيل عن بُعد | ✗ ممنوع نهائيًا بالتصميم | ✗ ممنوع نهائيًا بالتصميم |

الوحدة Swift رفيعة **عمدًا**: لا أوضاع خلفية (audio/location) كحيلة للالتفاف على قواعد Apple، ولا وعد بما لا تستطيع المنصة فعله. صفحة «ماذا يعمل على هاتفك؟» تُبنى من `src/core/explainer.ts` فلا تظهر ميزة مستحيلة على المنصة الخطأ.

## القواعد الذهبية (لا تُكسر أبدًا)

- لا تشغيل للصفارة عن بُعد على هاتف أي شخص آخر — أبدًا. (بلا خادم أصلًا: التطبيق **لا يستطيع** ذلك — ضمان هندسي، لا وعد تسويقي.)
- الصفارة تتوقف دائمًا بيد المالك (بصمة/وجه + رمز إيقاف + استرداد محلي).
- لا حساب، لا بريد، لا بيانات تخرج من الهاتف.
- لا وعد بميزة مستحيلة على منصة ما.
- الوضع **صارم فقط** (مهلة + صفارة فورًا) — لا وضع مهذب ولا مرحلة تحذير في الكود إطلاقًا (قرار §9/5).
- الإمساك بالهاتف وحده لا يلغي التسليح أبدًا.
- لا رمز طوارئ مموَّه — أُلغي نهائيًا بقرار عمرو (تحديث 00:35): يرفض الفكرة تمامًا، الأسرة في البيت ولا أحد يهدد أحدًا. لا يُبنى ولا يُعاد سؤاله.
